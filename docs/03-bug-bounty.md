# Bug bounty

Bug bounty nav CVD sinonīms. Atlīdzības mehānisms var motivēt pētniekus, bet tam nevajadzētu paplašināt testēšanas tvērumu, sajaukt tehnisko smagumu ar atlīdzības apmēru vai kavēt novēršanu atlīdzības strīda dēļ.

Apspriežams: pilotējama programma skaidri definētiem publiskiem resursiem ar scope, safe-harbour, aizliegtām darbībām, triāžas SLA, atlīdzības matricu un koordinētu disclosure.
