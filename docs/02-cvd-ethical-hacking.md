# CVD un labticīga drošības izpēte

- **CVD process** nosaka, kā ievainojamība tiek droši ziņota, koordinēta un novērsta.
- **CVD programma** nosaka konkrēto resursu, testēšanas tvērumu un nosacījumus.
- **Bug bounty** nosaka atlīdzības mehānismu un pats par sevi nepaplašina testēšanas tiesības.

Tēmas: safe-harbour, atļautā testēšana, pierādījumu minimizācija, termiņi, triāža, CERT.LV koordinācija un atbildības robežas.
