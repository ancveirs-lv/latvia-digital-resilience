# Institucionālā atbildība un laba pārvaldība

Šī sadaļa nav paredzēta individuālu strīdu vai personu apsūdzību publicēšanai.

Sistēmiski principi: atbilde pēc būtības; pārbaudāma faktu noskaidrošana; individuāla strīda nošķiršana no sabiedrības interešu jautājuma; whistleblowing, grievance un improvement procesu nošķīrums; aizsardzība pret nelabvēlīgām sekām; organizāciju mācīšanās.
