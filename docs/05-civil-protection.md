# Civilā aizsardzība un sabiedrības noturība

Jauna digitālā funkcionalitāte nedrīkst automātiski dublēt jau pastāvošas valsts spējas. Pirms jaunas sistēmas projektēšanas jāizvērtē 112/112 Latvija, LV-ALERT, VUCAP, brīvprātīgā darba sistēmas un valsts koplietošanas pakalpojumi.

Prioritātes: degraded/offline režīmi, sakaru un elektroapgādes traucējumi, brīvprātīgo lomas, pašvaldību/valsts plānu savietojamība un praktiski vingrinājumi.
