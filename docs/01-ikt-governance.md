# Valsts IKT pārvaldība un pierādāmība

## Virziens
Izmantot minimālu, mašīnlasāmu pierādījumu profilu, kas indeksē jau esošus kontrolētus pierādījumus, nevis centralizē sensitīvu saturu.

`ID + type + hash + status + owner + controlled reference + mapping`

Diskusijai: dzīves cikla izsekojamība, build/deployment provenance, emergency changes, VIRSIS un esošo pierādījumu atkārtota izmantošana.
