# Bug Bounty and incentives

## Source-backed baseline

Bug Bounty and vulnerability disclosure are related but not synonymous. CERT/CC treats bounty eligibility as something a disclosure policy should delimit, and CISA explicitly distinguishes a vulnerability disclosure policy from a Bug Bounty.

## Project recommendation

For a public-sector pilot, establish the disclosure and remediation process first, then add rewards as a separate layer.

A programme should define:

- eligible assets and vulnerability classes;
- prohibited actions;
- duplicate handling;
- report-quality requirements;
- triage and response expectations;
- reward criteria and caps;
- disclosure coordination;
- dispute and exception handling.

The reward matrix must not silently redefine authorization. A report can be useful without being reward-eligible, and reward eligibility should not determine whether a valid vulnerability is remediated.
