# Civil protection and continuity

## Source-backed baseline

Latvia already has public emergency-information capabilities including 112/112 Latvija. VUGD also reports that VUCAP has been implemented as a state information system supporting fire-safety and civil-protection management.

## Project recommendation

A new civil-protection digital function should begin with a capability map, not a blank architecture diagram.

Assess:

- whether an authoritative system already owns the function or data;
- integration and interoperability options;
- degraded and offline operation;
- communications and power loss;
- role hand-off between state, municipal, emergency-service, NGO and volunteer actors;
- data minimisation and access control;
- exercises, recovery and reconciliation after disruption.

New functionality is justified where it closes a documented gap that cannot be met safely through existing capabilities or integration.
