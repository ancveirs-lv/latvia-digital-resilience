# Latvia Digital Resilience

This site is a bilingual working reference for turning public-sector resilience ideas into **source-bounded, testable proposals**.

## How to read the project

Every substantive proposal should keep four layers separate:

| Layer | Question |
|---|---|
| Source-backed baseline | What already exists or is formally required? |
| Project recommendation | What change is being proposed? |
| Boundary | What does the cited evidence not establish? |
| Validation | How would we know whether the proposal worked? |

## Areas

The project covers public-sector ICT governance, CVD and security research, Bug Bounty design, cyber resilience, civil protection, election and critical-process resilience, and institutional accountability.

It deliberately prefers **interoperability and reuse before new central infrastructure**, while allowing new components where a documented gap and measurable benefit can be shown.

## Public-safety boundary

This site does not publish live exploitation detail, credentials, personal data, or unsupported accusations. Election material is technical and organisational and does not recommend any electoral choice.
