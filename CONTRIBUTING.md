# Contribution guidelines

Labs Issue vai Pull Request satur: problēmu, pierādījumus, ietekmi, konkrētu priekšlikumu, robežas un validācijas kritērijus.

## Neiesniegt
- ekspluatācijas instrukcijas pret dzīvu sistēmu;
- sensitīvus akreditācijas datus vai slepenas konfigurācijas;
- personas datus vai nepārbaudītas apsūdzības;
- politisku aģitāciju vai komerciālu reklāmu;
- nepārbaudītu ģenerētu saturu.

Dod priekšroku Latvijas normatīvajiem aktiem un institūciju dokumentiem, EUR-Lex, Eiropas Komisijai, ENISA, CERT.LV, ETSI, CEN/CENELEC, ISO/IEC, IETF, NIST un recenzētiem pētījumiem.
