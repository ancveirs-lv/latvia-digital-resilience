# Ieguldījumu vadlīnijas

Papildinājumi ir gaidīti, ja tie uzlabo pierādījumu kvalitāti, tehnisko precizitāti, īstenojamību vai divvalodu skaidrību.

Labs Issue vai Pull Request ietver:

1. risināmo problēmu vai apgalvojumu;
2. avotos balstīto sākuma stāvokli;
3. konkrētu priekšlikumu;
4. tvērumu un ne-mērķus;
5. riskus vai kompromisus;
6. izmērāmus validācijas kritērijus;
7. savstarpēji atbilstošas LV un EN izmaiņas, ja tiek mainīta publiskā dokumentācija.

## Avotu hierarhija

Priekšroka dodama:

1. Latvijas normatīvajiem aktiem un oficiāliem institūciju materiāliem;
2. EUR-Lex un ES institūciju avotiem;
3. CERT.LV, ENISA, FIRST, IETF, NIST un salīdzināmiem tehniskiem avotiem;
4. standartizācijas organizācijām un recenzētiem pētījumiem;
5. sekundārai analīzei tikai tad, ja nav pieejams stiprāks pirmavots.

Atsauce pati par sevi nepārvērš projekta priekšlikumu par faktu vai juridisku pienākumu.

## Neiesniegt

- ekspluatācijas instrukcijas pret dzīvu sistēmu;
- akreditācijas datus, noslēpumus vai ierobežotas konfigurācijas;
- personas datus;
- nepamatotas apsūdzības pret identificējamām personām vai organizācijām;
- partiju politisko aģitāciju;
- nepārbaudītu ģenerētu tekstu;
- materiālu, kas klusējot sajauc juridiskus pienākumus ar brīvprātīgu labo praksi.

Pirms Pull Request palaid `make check`.
