# Latvijas digitālā noturība / Latvia Digital Resilience

Publisks, atvērts priekšlikumu un pierādījumu repozitorijs Latvijas digitālās pārvaldības, kiberdrošības, koordinētas ievainojamību atklāšanas (CVD), ētiskas drošības izpētes, civilās aizsardzības un kritisko sabiedrisko procesu noturības uzlabošanai.

## Mērķis

Repozitorija mērķis nav veidot politisku manifestu vai institūciju kritikas arhīvu. Tas ir praktisks, pārbaudāms un papildināms darba materiāls, kur:
- problēma tiek nošķirta no risinājuma;
- fakti un normatīvais pamats tiek norādīti atsevišķi no viedokļa;
- priekšlikumiem jābūt samērīgiem, īstenojamiem un auditējamiem;
- sensitīva tehniskā informācija netiek publicēta;
- personiskas lietas netiek izmantotas kā publiska apsūdzību platforma;
- ikviens var iesniegt Issue vai Pull Request ar argumentētu papildinājumu.

## Kā iesaistīties
- **Issue** — problēma, priekšlikums, pierādījums, avota precizējums vai diskusijas jautājums.
- **Pull Request** — konkrēts teksta, struktūras, avotu vai metodikas uzlabojums.
- Priekšlikumiem jābūt balstītiem pārbaudāmos avotos.
- Drošības ievainojamības un ekspluatācijas detaļas šeit nepublicē. Skatīt [SECURITY.md](SECURITY.md).

## Pamatprincipi
- evidence before assertion;
- no duplicated public infrastructure without a demonstrated need;
- clear separation of legal obligations, voluntary practices and incentives;
- least privilege and secure-by-design;
- auditable decisions and change history;
- interoperability before bespoke duplication;
- public transparency where possible, controlled handling where necessary.

## English summary
**Latvia Digital Resilience** is an open, issue-driven repository for evidence-based proposals on public-sector ICT governance, cybersecurity, coordinated vulnerability disclosure, ethical security research, civil protection and resilience of critical democratic and public processes in Latvia.

Contributions are welcome through Issues and Pull Requests.
