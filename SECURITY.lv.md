# Drošības politika

Šis repozitorijs nav ievainojamību ziņošanas kanāls trešo pušu sistēmām.

Ja atrodi reālu ievainojamību Latvijas publiskā vai privātā resursā, nepublicē ekspluatācijas detaļas Issue. Izmanto resursa pārziņa publicēto ievainojamību ziņošanas kanālu vai piemērojamo CERT.LV koordinētās ievainojamību atklāšanas procesu.

Ja ievainojamība attiecas uz šī repozitorija automatizāciju vai vietni, izmanto GitHub privāto ievainojamību ziņošanu, ja tā ir pieejama. Publiskos Issue neievieto akreditācijas datus vai noslēpumus.

Diskusijas par CVD, safe-harbour dizainu, triāžu, tvērumu, pierādījumu minimizāciju un sistēmiskiem uzlabojumiem ir gaidītas, ja netiek atklāts dzīvs mērķis.
